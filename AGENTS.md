# SLDGraph-X

Build a local-first, graph-first electrical SLD intelligence prototype. The central output is an explainable, attributed source-to-feeder graph—not merely detected symbols.

- Prioritize P0 workflow reliability before novelty or polish.
- Preserve evidence provenance and uncertainty; never silently invent topology.
- Do not claim unmeasured metrics, IEC compliance, power-flow simulation, or external integrations.
- Keep inference adapters separate from graph/domain logic.
- Make engineer corrections auditable and recompute affected graph reasoning.
- Keep judging-critical paths offline and avoid new cloud dependencies.
- Test and run the real workflow before declaring a milestone complete.
- Use coherent commits only after verified checkpoints.
