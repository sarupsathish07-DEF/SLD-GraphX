# Data

Large source drawings, generated synthetic sets, and model weights are intentionally ignored by Git. Use only documented, permitted sources. Bootstrap fixtures are source code data, not a benchmark claim. Milestone 3 Symbol-v1 is regenerated locally from `scripts/create_symbol_dataset.py`; its tracked specification fixes vocabulary, whole-drawing split policy, and tile policy while generated images/annotations/manifests remain ignored. Milestone 4 topology-v1 is regenerated by `scripts/create_topology_benchmark.py`; the tracked spec fixes six topology families, A/B/C test and D holdout styles, and equipment-endpoint scoring while images, manifests, degradations, and results stay ignored. M4R uses the separate `scripts/create_topology_repair_development.py` E/F corpus only for development/validation; it never replaces the frozen topology-v1 evidence.
