# Confidence model

Confidence records reliability of observed or inferred objects. Physical connections retain M4 visual/terminal evidence. M5 path confidence is the geometric mean of constituent physical edge confidence and always exposes the weakest edge; it is not a calibrated probability. Review risk is uncertainty (`1 - edge confidence`) times configured topology impact factors (affected feeders/nodes, source assignment change, bridge, components). Engineer verification adds provenance without deleting prior history.
