# Milestone 5 demo script

1. Open the local workspace.
2. Confirm the LOCAL indicator and backend health status.
3. Upload a SLDForge drawing and complete analysis.
4. Search a resolved feeder in **Trace** and inspect source, source bus, exact path, confidence, and weakest edge.
5. Open **Review** and inspect topology consequence before accepting/rejecting an issue.
6. In **Scenario**, change a switch temporarily, simulate connectivity, then optionally save a reviewed state.
7. Compare **Original**, **Reconstructed**, and **Graph**; export the local full ZIP package.

This validates local graph-to-trace-to-review-to-scenario-to-export behavior. It is not power-flow or a real-utility demonstration.
